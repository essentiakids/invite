# Wedding Invitation — M. Arslan Tasawar

A lightweight, elegant wedding invitation website for GitHub Pages. Built in HTML, CSS, and JavaScript; no build step or server is required.

## Details
- Date: Saturday, 21 November 2026
- Barat arrival: 6:00 PM PKT
- Walima / Dinner: 7:00 PM PKT
- Venue: Hafizabad Gymkhana, opposite District Complex, Hafizabad

## Features
Animated welcome invitation, premium burgundy-and-gold responsive design, floral falling-petal effect, scroll transitions, event schedule, countdown, venue directions, contact links, and downloadable calendar event.

## GitHub Pages
Go to **Settings → Pages → Build and deployment**, select **Deploy from a branch**; choose **main** and **/(root)**, then save. The intended site address is https://essentiakids.github.io/invite/ .

## Artwork
The site includes an editable SVG recreation in `assets/invitation-card.svg`. To display the exact supplied printed card instead, upload `assets/original-invitation.jpg` and replace `assets/invitation-card.svg` with `assets/original-invitation.jpg` in `index.html`.

## Customizing
Edit wedding details in `index.html`; update the countdown date and calendar times in `script.js`; update palette and typography in `styles.css`.
